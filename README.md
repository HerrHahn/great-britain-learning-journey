# Great Britain · Past & Present

English Year 13 LK, Hessen · Autumn 2026. Static learning portfolio for GitHub Pages.

15 chapters, 47 teaching lessons plus a provisional 3-lesson exam allocation on 6 November 2026. Start assumed 28 September; autumn holidays excluded; completion 18 December with 21–22 December as timetable-dependent buffer.

Open index.html through a local web server or GitHub Pages. No build step or external student-data service. On the teacher’s request, original readings and book tasks are included in four reading packets, with page images for annotation. The separate seven-slide Cambodia deck takes precedence over the older deck in the ZIP.

Features: local saving, validated .britain.json import/export, chapter/full PDF export, native iPad Scribble-friendly fields, teacher feedback, five writing drills and optional 120-minute Advanced Test. Actual Apple Pencil handwriting conversion is provided by iPadOS, not the site.

Only this directory belongs in the public repository. The complete source files and teacher handbook stay outside it; only the requested reader extracts and three illustrations are included. Source notes and font licenses are included.
